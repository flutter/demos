# Flutter and Dart demos

This repo is for code and projects that support talks, blogs, and experiments.

> [!NOTE]
> Projects and code in this repository are for **demonstration purposes only**.
> The code is unmaintained, quality and accuracy aren't guaranteed,
> and projects might not work with newer releases of Flutter and Dart.
>
> Demos might be removed at any time without warning,
> such as when they are no longer maintained or in focus.

## Demo validation

This repository doesn't have CI set up,
so demos aren't automatically analyzed or tested.
If you want to verify your demo,
validate it locally before opening a PR.
If the demo is still valid or used,
consider occasionally revalidating and updating the demo.

## Archived demos

Projects that are no longer useful or too out of date
can be moved to the top-level [`_archive/`](_archive) directory.
This distinction from a top-level demo is purely cosmetic,
and really only signals to readers that you no longer care about this code.
